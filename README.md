## Tech Stack

- **Framework**: Expo 55 with Expo Router
- **Language**: TypeScript
- **UI**: React Native 0.83

## Getting Started

### Prerequisites

- Node.js and npm

### Local Setup

1. **Clone the repository**

```bash
git clone https://github.com/sameerbhagtani/simple-auth-ui.git
```

2. **Install dependencies**

```bash
npm install
```

3. **Start the development server**

```bash
npm start
```
